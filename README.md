# HITS

HITS - Home Inventory Tracking System

# Description

This app has the purpose of tracking goods contained at a home premises and being able to create, read, update and delete from the database via user interaction.

It uses:
* NPM for package management
* JavaScript / TypeScript for the main language
* Expo for React Native Support
* CouchDB on server
* PouchDB for offline
* ExpressJS for Server-Side Processing

Additionally components possibly desired by the user:\
An external device like a Raspberry Pi, Laptop or Spare PC for server duties.

Target Audience: Users with large inventory or home inventory spaces like cellars where they want to keep track of contents.

Minimum Viable Product:\
* Input entries
* Edit amount of items in entry
* Remove entries
* Store entries in a DB file on a local server

# Installation / Usage
You need:
* NodeJS
* NPM
* Android SDK

# Navigation
Run the app from `./frontend/HITS`
Run the server from `./backend`
